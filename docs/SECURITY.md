# Security Policy

## Reporting Security Vulnerabilities

We take security vulnerabilities and appreciate responsible disclosure seriously.

**Please DO NOT report security vulnerabilities through public GitHub issues.**

### How to Report

**Email:**
- Email: `czarerebus@tutamail.com`
- Subject: `[SECURITY] Vulnerability Report - Erebus Marketplace Script`

### What to Include

Please include the following information in your report:

- **Description**: Short description of the vulnerability
- **Steps to Reproduce**: Detailed steps to reproduce the issue
- **Suggested Fix**: If possible, include your suggested solution
- **Contact Information**: How I can reach you for follow-up (if needed)

## Acknowledgments

Developers who contrinute to The Erebus Marketplace Script through critical bug reports and security-related pull requests will be acknowledged here if they wish so.
